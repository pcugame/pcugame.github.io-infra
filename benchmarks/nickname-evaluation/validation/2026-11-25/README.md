# Qwen3 4B 능동 조사 검증 기록

2026-11-25 KST에 `lab` 작업 트리에서 실제 Qwen3-4B-Instruct-2507-Q4_K_M과 기존 SearXNG로 두 닉네임의 세 검색 모드를 확인하였다. 제한된 조사 절차, 자료 인용, JSON 계약과 자원 상한의 검증 기록이다. 두 사례는 개발 중 동작 확인에 사용하였으며 독립적인 정확도 평가 집합이 아니다. 전체 데이터셋의 성능 향상이나 혼합 문자 복원 능력을 입증하지 않는다.

각 평가 JSON에는 모델 가중치와 실제 chat template의 hash, 엔진 버전, 시스템 지침, 단계별 입력·schema·설정, 모델 해석 후보와 검색어, 검색 결과, 실제 제공한 발췌문, 인용 검사, 최종 점수·근거·출처 ID·유보 여부, 토큰 수·시간을 포함한다. URL은 `sources`의 Worker 수집 기록과 `output.sourceIds`로 결합한다. 관리용 기대 근거나 점수는 모델에 전달하지 않았다. 모델의 전체 내부 사고 과정은 요청하지 않았다.

`틀딱대장`의 능동 조사에서는 모델이 `틀딱`, `틀딱 대장`을 검색하였다. 네 번의 생성과 두 번의 검색으로 최종 판단을 생성하였으며, 마지막 판단 생성은 입력 1,907·출력 469토큰이었다. 모델은 노인 비하 표현의 뜻을 설명하는 S1·S4 발췌문을 인용하고 30점을 제시하였다. 30점은 모델의 출력이며 검증된 정답 점수가 아니다. 자체 지식 모드와 선검색 모드의 설명에는 표현의 뜻을 잘못 해석한 내용이 남아 있다.

`ㅅ丨발장군`에서는 모델이 `사丨발장군` 등의 부정확한 가설을 제안하였다. 올바른 복원에 성공하지 않았으며, 마지막 응답은 `unverified_hypothesis`와 점수 `null`을 기록하였다. 첫 최종 응답은 미검증 가설에 점수를 부여해 Worker가 거부하였고, 같은 전체 상한 안에서 한 번 재생성하였다. 판단 유보로 점수 확정을 막았으나 근거 문장 자체의 부정확성까지 제거된 것은 아니다.

모든 자료는 검색 제목·발췌문이다. 원문 페이지를 열거나 읽었다고 처리하지 않았다. 일부 검색 결과 URL은 항목 본문 대신 사이트 첫 화면을 가리킨다. 수집된 URL을 임의로 보정하지 않았으므로 사람의 원문 확인이 추가로 필요하다. 정확한 인용문 일치와 ID 대응 검사는 의미적 타당성을 보장하지 않는다.

## 자원 측정과 예산

GTX 1660 6,144MiB에서 37/37 layer를 CUDA에 배치하였다. 엔진은 llama.cpp b12559 (`7e960f40f`)이며, 가중치 SHA-256은 `3605803b982cb64aead44f6c1b2ae36e3acdb41d8e46c8a94c6533bc4c67e597`이다. f16 KV cache는 432MiB, CUDA 모델 버퍼는 2,375.91MiB, compute 버퍼는 80.01MiB였다.

GPU 호스트의 0.5초 간격 NVML 표본은 GPU 사용량 3,026MiB, 여유 2,715MiB를 기록하였다. 이는 GPU 전체의 표본 사용량이며 PyTorch allocator의 peak 값이 아니다. 중립 문장의 실제 입력 1,023토큰에서는 약 6.9초, 1,983토큰에서는 약 11.3초가 소요되었다. 두 길이 모두 출력은 149토큰이었으며 생성 속도는 약 48~51토큰/초였다. 입력 처리까지 포함한 속도와 생성 구간 속도는 JSON에서 별도로 확인할 수 있다.

최종 인용·판단 JSON은 469토큰으로 기존 출력 256토큰을 초과하였다. 생성당 입력 2,048·최종 출력 768·컨텍스트 3,072토큰을 선택하였고, action은 320토큰으로 제한하였다. 한 닉네임의 상한은 검색 2회·생성 5회·누적 입력 8,192·누적 출력 2,304토큰·240초다. 근거 압축과 단계별 생성으로 컨텍스트 확대를 제한한다. 합성 길이 측정에서 최대 768토큰을 모두 생성한 것은 아니며, 이는 최악 지연시간 벤치마크가 아니다.

## 구조화 출력 호환성

실제 GGUF template와 b12559를 사용해 확인하였다. `/v1/chat/completions`는 짧은 schema에서 성공하였으나 긴 응답에서는 Qwen 출력 파서 오류와 JSON 뒤의 추가 문장이 발생하였다. 연구 프로파일은 `/apply-template`와 `/tokenize`의 실제 토큰을 `/completion`에 전달하고 JSON schema로 제한한다.

기존 Unicode scalar 검증 정규식을 문자열 GBNF에 그대로 적용했을 때 따옴표·줄바꿈을 허용하는 문제가 관측되었다. 생성용 JSON 문자열에서는 이 정규식을 제거하고 Worker의 Unicode 검사를 유지하였다. 최종 단일 비교는 JSON 금지 지침과 고정 schema를 충돌시킨 시작 검사를 통과한 서버에서 실행하였다. 혼합 문자 비교와 길이 측정은 같은 생성 구현·모델·template로 수행하였으며, 시작 검사를 강화하기 전의 프로세스를 사용하였다. 실제 action·최종 판단 schema를 포함한 최종 여섯 결과는 모두 유효한 JSON으로 종료하였다. 이 중 혼합 문자 능동 조사는 의미 검증 실패 후 한 번 재생성하였다.

## 자동 검증과 운영 상태

Fake Provider 검증은 모델의 추론 품질 검증과 구분한다. Worker 테스트는 검색 실패, 무관한 검색 결과, JSON 오류·출력 잘림, 반복 질의, 미검증 복원 점수, 위조 ID·인용, 악의적 웹 지침·template 제어 토큰·임의 fetch action, 전체 deadline과 취소를 확인하였다. 원문 fetch는 구현하지 않았으며 검색 결과 URL로의 네트워크 요청도 실행하지 않는다.

로컬 검증 결과는 다음과 같다.

- API 전체 단위 테스트: 1,273개 통과. 환경 의존 테스트 345개 제외. 이후 유보 조건 보강에 대해 연구 Worker 9개와 기존 평가 22개를 추가 확인하였다.
- PostgreSQL·인증된 API·독립 Worker: 기존 평가·저장소·신규 연구 통합 테스트 11개 통과. 최종 계약 수정 후 신규 연구 통합 테스트를 다시 확인하였다. 모델·검색 응답은 Fake HTTP Provider다.
- 계약 테스트 194개, Python 서버 테스트 7개, Web 연구 화면 테스트 2개 통과.
- API lint·architecture·build, Web 변경 파일 lint·build 통과. Web build에는 큰 bundle과 `use no memo` 관련 경고가 남아 있다.
- runtime 환경 키 검사 14개와 통합 실행기 테스트 34개 통과.

사용자 요청에 따라 `gameserver`의 `qwen-coder.service`를 중지하고 자동 시작을 해제하였다. 기존 파일·가중치는 보존하였다. 기존 `gh-deploy`의 `gp-lab-search`를 재사용하였으며 운영 검색 컨테이너 설정은 변경하지 않았다. 검증에 사용한 임시 연구 서버·검색 전달 프로세스·SSH 터널은 종료하였다. 운영 API·Worker·Web에는 이번 코드를 배포하지 않았고, 저장소 변경은 `lab`의 미커밋 작업 트리 상태다. 커밋·푸시·CI·병합은 수행하지 않았다.

설정과 재실행 명령은 [Lab 운영 문서](../../../../docs/operations/nickname-evaluation-lab.md#단일-평가와-비교-실행), 서버 실행은 [연구 서버 문서](../../../../server/local-llm/README.md)에 있다. 모델 확대, 상용 LLM 위임, 파인튜닝은 수행하지 않았다.
